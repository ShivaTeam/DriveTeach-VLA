# DVD (Driving-aware Vision Distillation) & SFT Training

## Overview

DriveTeach-VLA training consists of three stages implemented in this directory:

1. **DVD Pretraining** (`distill_tgp_prompter.yaml`) — trains the TGP-Prompter ViT encoder via self-distillation from bbox-augmented images. The language model and projector are frozen; only the ViT encoder receives distillation loss.
2. **TGP-Prompter SFT** (`../sft/train_tgp_prompter.yaml`) — full fine-tunes the TGP-Prompter to predict 2D-TGP trajectories from front-view images.
3. **TGP-Planner SFT** (`../sft/train_tgp_planner.yaml`) — initializes from the distilled model, then full fine-tunes for CoT reasoning and BEV trajectory prediction.

## Directory Structure


## Installation

We suggest creating two separate conda environments: one with the patched libraries for DVD training, and one with the official releases for SFT. The patched versions are only needed for DVD.

```bash
# Create DVD conda environment
conda create -n driveteach python=3.10 -y
conda activate driveteach
pip install torch torchvision --index-url https://download.pytorch.org/whl/cu121

# Install patched transformers
cd transformers-4.50.0
pip install -e .
cd ..

# Install patched LLaMA-Factory
cd LLaMA-Factory
pip install -e ".[torch,metrics]"
pip install deepspeed>=0.16.0
cd ..
```

## Usage

### Step 1: Build training datasets

Generate the training data using the DriveTeach-VLA data engine (see `../data_engine/README.md`):

```bash
cd ../data_engine
python main.py --config configs/pipelines/prompter.yaml
python main.py --config configs/pipelines/planner.yaml
```

This produces `QA_navsim_train_prompter.json` and `QA_navsim_train_planner.json` in the `output/` directory.

### Step 2: Modify the config

Update the following paths in the YAML config files:
- `distill_tgp_prompter.yaml`: set `model_name_or_path` to your Qwen2.5-VL-3B checkpoint
- `train_tgp_prompter.yaml` / `train_tgp_planner.yaml`: set `dataset_dir` to point to the `output/` directory

### Step 3: DVD Pretraining

```bash
conda activate driveteach
llamafactory-cli train dvd/distill_tgp_prompter.yaml
```

Trains the ViT encoder with DVD self-distillation loss. Output saved to `./models/distill_tgp_prompter`.

### Step 4: TGP-Prompter SFT

```bash
conda activate llamafactory
llamafactory-cli train sft/train_tgp_prompter.yaml
```

Trains the distilled Prompter on 2D-TGP regression. Output saved to `./models/train_tgp_prompter`.

### Step 5: TGP-Planner SFT

```bash
conda activate llamafactory
llamafactory-cli train sft/train_tgp_planner.yaml
```

Trains the Planner for CoT reasoning + normalized BEV trajectory prediction. Output saved to `./models/train_tgp_planner`.

## DVD Config Parameters

| Parameter | Description |
|-----------|-------------|
| `enable_dvd` | Enable DVD distillation |
| `dvd_h_size` | Block count along height for regional loss |
| `dvd_w_size` | Block count along width for regional loss |
| `dvd_tgp_weight` | Weight for TGP loss in total loss |
| `dvd_ema` | EMA decay for teacher ViT |

When `enable_dvd=true`, the following happens automatically:
- `bbox_image` from the dataset is appended to the image list (doubles image count per sample)
- `h_size/w_size/vit_loss_weight/ema_decay` are injected into the model config before loading
- Student ViT weights are copied to teacher ViT on initialization
- EMA teacher update runs after each optimizer step
